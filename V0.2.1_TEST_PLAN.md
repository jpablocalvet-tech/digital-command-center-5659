# V0.2.1 — Test Plan

## A. Existing V0.2 data survives

1. Run `bun run db:push` against the existing local database.
2. Start the app and open RUTA · Octubre 2026.
3. Confirm existing Founder Hours, approvals, pipeline and automation values remain.

## B. New client with initial cycle

1. Open **Clientes** → **Nuevo cliente**.
2. Create a test external client, for example `Cliente 001`.
3. Leave **Crear ciclo inicial** enabled.
4. Add cycle name, dates and a business priority.
5. Save.
6. Confirm the new client appears in the client selector and Clients screen.
7. Confirm its Client Hub opens and the initial cycle is selected.
8. Confirm Strategy Lab and AI Team have empty/default records for that cycle.

## C. New client without a cycle

1. Create another test client with **Crear ciclo inicial** disabled.
2. Open its Client Hub.
3. Confirm the empty state says the client has no cycles and offers **Crear primer ciclo**.
4. Create the first cycle and confirm the Client Hub becomes operational.

## D. New cycle for an existing client

1. Open RUTA Client Hub.
2. Click **Nuevo ciclo**.
3. Create a planned cycle and verify it appears in the cycle selector.
4. Create an active cycle and confirm any previous active cycle is closed automatically.

## E. UX polish

1. Open an approved content item.
2. Confirm approval history shows human labels such as **Aprobado** and **Listo para aprobación**, not internal codes.
3. Confirm Content Detail uses the revised Spanish labels.
